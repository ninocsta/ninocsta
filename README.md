# Olá, sou Nicolas Costa 👋

**Tech Lead & Desenvolvedor Full Stack** — desenho, construo e opero sistemas web de ponta a ponta, da modelagem e APIs ao front-end e à produção.

Na **Minesoft** lidero a parte técnica de uma plataforma de marketplace e de uma operadora móvel virtual (~40 serviços): arquitetura, código, code review, incidentes e plataforma — migrei o staging para o Coolify (49 apps) e sou coautor de ferramentas de API gateway em Go. Pela **NKC Dev** entrego sistemas e produtos SaaS para 5+ clientes (multi-tenant, pagamentos, automação de WhatsApp), com 10+ apps em produção numa plataforma Coolify própria.
